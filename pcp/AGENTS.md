# Forma de trabajo en el repositorio

## Resolución de guías

- Para cada guía, tomar el archivo PDF correspondiente como enunciado de referencia.
- El estudiante escribe sus ideas y borradores en el archivo Markdown correspondiente.
- No completar, corregir ni reformatear un ejercicio hasta que el estudiante lo pida explícitamente.
- Cuando el estudiante pida revisar un ejercicio, contrastar primero su propuesta con el enunciado y verificar que la solución sea correcta.
- Si la idea es correcta, editar el Markdown para dejarla clara y prolija, conservando el razonamiento del estudiante y agregando el código o pseudocódigo necesario.
- Si la idea tiene un error conceptual o no satisface alguna condición del ejercicio, no modificar ese ejercicio: explicar qué falla y esperar una nueva propuesta o una indicación explícita para corregirlo.
- No reemplazar silenciosamente una solución dudosa por una solución propia.
- Mantener un formato consistente entre ejercicios: título, explicación breve, definiciones relevantes y código o pseudocódigo cuando corresponda.
- Usar español y respetar la notación y el nivel de detalle que ya tenga el documento.
